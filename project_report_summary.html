PROJECT DOCUMENTATION & REPORT GUIDE

ระบบบริหารจัดการการจองตั๋วภาพยนตร์ดาราศาสตร์และจุดจำหน่ายตั๋วหน้าร้าน

ศูนย์วิทยาศาสตร์เพื่อการศึกษารังสิต (ท้องฟ้าจำลองรังสิต)

Rangsit Planetarium Showtime Ticketing & Point of Sale (POS) Management System

บทที่ 1: บทนำและความเป็นมา (Introduction & Background)

1.1 ความเป็นมาและความสำคัญ

ศูนย์วิทยาศาสตร์เพื่อการศึกษารังสิต (ท้องฟ้าจำลองรังสิต) เป็นแหล่งเรียนรู้ด้านดาราศาสตร์และวิทยาศาสตร์ที่สำคัญของประเทศไทย ให้บริการฉายภาพยนตร์ดาราศาสตร์เต็มโดมความละเอียดสูง (Full Dome Digital Planetarium) ขนาด 160 ที่นั่ง โดยมีผู้เข้าชมหลากหลายกลุ่ม ทั้งนักเรียน นักศึกษา หน่วยงานราชการ คณะทัศนศึกษา และประชาชนทั่วไป

ปัญหาและความท้าทายเดิม:

  • การเข้าถึงข้อมูลรอบฉายและที่นั่งว่าง: ผู้เข้าชมไม่ทราบจำนวนที่นั่งว่างล่วงหน้าก่อนเดินทางมาถึง
  • ความแออัดบริเวณจุดจำหน่ายตั๋ว: ในช่วงวันหยุดการจำหน่ายตั๋วหน้าร้านใช้เวลาคีย์ข้อมูล ส่งผลให้แถวคอยยาว
  • การคัดกรองประเภทผู้เข้าชม: การแยกประเภทบุคคลทั่วไป, โรงเรียน, และหน่วยงานมักเกิดความผิดพลาด
  • ความล่าช้าในการตรวจตั๋ว: ขาดระบบสแกนตรวจตั๋วดิจิทัลที่สามารถป้องกันการใช้ตั๋วซ้ำได้อย่างมีประสิทธิภาพ
  • ขาดข้อมูลสถิติเชิงลึก: ผู้บริหารไม่สามารถเรียกดูรายงานสรุปรายได้และสถิติภาพยนตร์ยอดนิยมแบบ Real-time

1.2 วัตถุประสงค์ของโครงงาน

  1. เพื่อพัฒนาเว็บไซต์ให้บริการตรวจสอบตารางรอบฉาย และจองตั๋วภาพยนตร์ดาราศาสตร์แบบออนไลน์ล่วงหน้า
  2. เพื่อพัฒนาระบบเลือกที่นั่งตามผังห้องฉายโดมดาราศาสตร์ (Dome Seating Map) ขนาด 160 ที่นั่ง แบบ Real-time
  3. เพื่อพัฒนาระบบชำระเงินดิจิทัลผ่าน PromptPay QR Code และออกบัตรเข้าชมอิเล็กทรอนิกส์ (E-Ticket)
  4. เพื่อพัฒนาระบบจุดจำหน่ายตั๋วหน้าร้าน (Staff POS) พร้อมฟังก์ชันขายด่วน (Quick Sell) และพิมพ์สลิปความร้อน 80mm
  5. เพื่อพัฒนาระบบสแกนตรวจตั๋วเข้าชม (Ticket Check-in Scanner) ด้วยกล้องอุปกรณ์หรือเครื่องยิงบาร์โค้ด
  6. เพื่อพัฒนาระบบผู้ดูแลระบบและแดชบอร์ดสรุปสถิติวิเคราะห์สำหรับผู้บริหาร (Executive Analytics Dashboard)

บทที่ 2: ขอบเขตของโครงงาน (Project Scope)

1. ผู้เข้าชมทั่วไป (Visitor / Public)

  • ดูตารางรอบฉายประจำสัปดาห์ (วันอังคาร–อาทิตย์) แสดงสถานะที่นั่งว่าง Real-time
  • ระบบจองตั๋ว 4 ขั้นตอน: กรอกข้อมูล, เลือกที่นั่งบนผังโดม 160 ที่, ชำระเงิน PromptPay, รับบัตร E-Ticket
  • จำกัดโควตา: บุคคลทั่วไปสูงสุด 10 ที่นั่ง, โรงเรียน/หน่วยงานสูงสุด 160 ที่นั่ง
  • ระบบค้นหาตั๋วและตรวจสอบสถานะ (Track Booking) ด้วยเบอร์โทรหรือรหัสจอง

2. เจ้าหน้าที่จำหน่ายตั๋ว (Staff POS)

  • ระบบเข้าสู่ระบบเจ้าหน้าที่ (Staff Authentication)
  • ระบบขายด่วน (Quick Sell 1-Click): เลือก 1, 2, 3, 5, 10 ใบ ตัดที่นั่งให้อัตโนมัติในคลิกเดียว
  • รองรับการรับชำระทั้งเงินสด (Cash) และ PromptPay QR
  • พิมพ์สลิปตั๋วความร้อนมาตรฐาน 80mm พร้อม QR Code ประจำใบ

3. เจ้าหน้าที่ตรวจตั๋ว (Gate Check-in)

  • สแกน QR Code ตรวจตั๋วผ่านกล้องเว็บแคม, กล้องมือถือ หรือเครื่องยิงบาร์โค้ด USB
  • ระบบป้องกันการใช้ตั๋วซ้ำ (Double Check-in Protection)
  • เสียงสัญญาณสังเคราะห์แจ้งเตือนผล (Web Audio API)
  • ตารางประวัติผู้เข้าชมที่สแกนผ่านประตูแล้วแบบเรียลไทม์

4. ผู้ดูแลระบบและผู้บริหาร (Admin)

  • จัดการข้อมูลภาพยนตร์, แม่แบบตารางสัปดาห์, รอบฉาย, และรายการจอง
  • ระบบสร้างรอบฉายอัตโนมัติ (1-Click Generator): ล่วงหน้า 7 วัน, 14 วัน, สิ้นเดือน, ตลอดเดือนถัดไป
  • Executive Analytics Dashboard: กราฟแนวโน้มรายได้, สัดส่วนกลุ่มผู้เข้าชม, และอันดับภาพยนตร์ยอดนิยม

บทที่ 3: สถาปัตยกรรมและเทคโนโลยีที่ใช้พัฒนา (Technical Architecture)

ส่วนของระบบ เทคโนโลยี / เครื่องมือ หน้าที่การทำงาน
Backend Core Laravel 11.x (PHP 8.2+) สถาปัตยกรรม MVC, Eloquent ORM, Routing, Security, Database Transactions
Admin Engine Filament PHP v3 (Livewire 3) ระบบจัดการหลังบ้าน, Form & Table Builders, Modal Actions, Metric Widgets
Database MySQL / SQLite จัดเก็บข้อมูลภาพยนตร์, ตารางรอบฉาย, ข้อมูลการจอง และผู้ใช้งาน
Frontend / CSS Blade Templates & Tailwind CSS v4 การแสดงผลแบบ Responsive รองรับทั้งคอมพิวเตอร์และอุปกรณ์เคลื่อนที่
Typography & Icons IBM Plex Sans Thai + Vector SVG ฟอนต์ภาษาไทยมาตรฐานองค์กร และไอคอนเวกเตอร์มินิมอลไม่มีอิโมจิ
QR Code Engine SimpleSoftwareIO/simple-qrcode สร้าง QR Code PromptPay สำหรับจ่ายเงิน และ Ticket Reference สำหรับตรวจตั๋ว
Camera Scanner html5-qrcode (JavaScript) สแกนถอดรหัส QR Code ผ่านกล้องเว็บแคมและกล้องสมาร์ตโฟนแบบเรียลไทม์

บทที่ 4: ประโยชน์ที่ได้รับจากโครงงาน (Project Benefits)

1. ด้านผู้รับบริการ (ผู้เข้าชม): เพิ่มความสะดวกในการวางแผนและสำรองที่นั่งล่วงหน้า 24 ชม. สามารถเลือกตำแหน่งที่นั่งที่พึงพอใจ และได้รับบัตรดิจิทัลทันทีโดยไม่ต้องต่อคิว

2. ด้านผู้ให้บริการ (ศูนย์วิทยาศาสตร์และเจ้าหน้าที่): ลดความแออัดหน้าเคาน์เตอร์ จุดขายตั๋วหน้าร้านออกตั๋วได้รวดเร็วภายใน 5 วินาที กระบวนการตรวจตั๋วหน้าทางเข้าแม่นยำ ป้องกันการใช้ตั๋วซ้ำได้ 100%

3. ด้านการบริหารจัดการ (ผู้บริหาร): มีแดชบอร์ดสรุปสถิติรายได้และข้อมูลเชิงลึกแบบ Real-time ช่วยสนับสนุนการวางแผนรอบฉายและการคัดเลือกสื่อภาพยนตร์ดาราศาสตร์ได้อย่างมีประสิทธิภาพ
